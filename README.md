# y.aoi

Capture ideas on your phone, print them as receipt slips for your wall.

- `index.html`: the app
- `config.js`: your Supabase URL and key (the only file you edit)
- `setup.sql`: run once in Supabase to create the database
- `manifest.webmanifest`, `icons/`: home-screen icon

Direct printing uses WebUSB, so it works in Chrome or Edge on a computer with the printer plugged in.
